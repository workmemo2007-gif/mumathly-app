# ممثلي — تطبيق شعبتك الجامعية

تطبيق ويب عربي (RTL) يعمل كـ PWA، مرتبط بقاعدة بيانات Supabase الخاصة بك، **بدون أي خطوة بناء**: ارفع الملفات إلى GitHub وفعّل Pages فيعمل.

## النشر على GitHub Pages
1. أنشئ مستودعاً جديداً على GitHub، وارفع **محتويات** هذا المجلد (ملف `index.html` يجب أن يكون في جذر المستودع).
2. من **Settings ← Pages**: اختر Source = *Deploy from a branch* ثم الفرع `main` والمجلد `/ (root)`.
3. افتح الرابط الذي يظهر (يشبه `https://اسمك.github.io/اسم-المستودع/`).

## إعدادات Supabase المطلوبة (مرة واحدة)
1. **Authentication ← Sign In / Providers ← Phone**: فعّله. التطبيق يسجّل بالهاتف + كلمة المرور.
   - لتجنب الحاجة لمزوّد SMS: عطّل **Confirm phone** (سيدخل المستخدم مباشرة بعد التسجيل). إن أبقيته مفعلاً فيجب ربط مزوّد SMS وسيطلب التطبيق رمز التحقق.
2. **Authentication ← URL Configuration**: ضع رابط GitHub Pages في *Site URL*.
3. تعيين الممثل الأعلى: أنشئ حساباً من التطبيق برقم `07723681360` ثم شغّل في SQL Editor:
   ```sql
   update auth.users set raw_app_meta_data = coalesce(raw_app_meta_data,'{}'::jsonb) || '{"is_super_admin":true}'::jsonb where phone = '9647723681360';
   ```
   ثم سجّل الخروج والدخول: يصبح الحساب ممثلاً فعّالاً تلقائياً ويرى قسم الإدارة. (الصلاحية محفوظة في قاعدة البيانات وليست في كود الواجهة.)

## ما الذي يعمل
الحسابات والموافقات، الأدوار والصلاحيات، الجدول، التبليغات (+إعجاب وتثبيت)، المكتبة (مواد/أنواع/رفع/مراجعة/تنزيل/إرسال في محادثة)، دردشة عامة لحظية (حذف 24 ساعة)، محادثات خاصة (نص/صورة/فيديو/صوت/ملف مكتبة + حذف 24 ساعة اختياري)، المهام، المنبهات الصوتية، الإشعارات، لوحة الإدارة وسجل العمليات. **تم حذف البث الجماعي.**

## ملاحظات صادقة
- المنبه والإشعار الصوتي يعملان والتطبيق مفتوح؛ إشعارات Push الخارجية (والتطبيق مغلق) تحتاج خادماً خاصاً وغير مشمولة.
- بعد التعديل على الملفات في GitHub قد يحتاج المتصفح لتحديث الصفحة مرة لتظهر النسخة الجديدة.
- لتعديل الألوان: `css/style.css` (المتغيرات في أعلى الملف). لتغيير مشروع Supabase: `js/config.js`.
